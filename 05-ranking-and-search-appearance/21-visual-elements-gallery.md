# Visual Elements gallery of Google Search

> Source: https://developers.google.com/search/docs/appearance/visual-elements-gallery
> Last updated: 2026-02-04 UTC

Visual elements are the building blocks of the Google Search results page that a user can perceive or interact with. The Visual Elements gallery is an illustrated guide to the most common UI elements of Google web search: it explains what the elements look like, what they're called, and whether you can optimize your website for each element.

## Anatomy of a Google Search results page

The Google Search results page contains a set of different types of search result visual elements. Here are the most common types:

### Text result
A result based on the textual content of the page. Includes visual elements such as attribution, title link, and snippet.

### Rich result
A result that typically relies on structured data in the markup of your page to display graphical elements or interactive experiences.

### Image result
A result based on an image that's embedded on that web page. More likely to show for image-seeking queries.

### Video result
A result based on a video that's embedded on that web page. More likely to show for video-seeking queries.

### Exploration features
A feature that helps searchers expand and refine their initial search.

## Attribution

Attribution describes the source of a search result, and can appear for a variety of search result types, including text, image, and video results. Attribution includes:

- **Favicon**: The small icon associated with the site. Learn how to provide a favicon.
- **Site name**: The name of the site. Learn how to provide a site name with structured data.
- **Visible URL**: The URL shown in a readable format (domain + breadcrumb).
- **Domain**: The site address as defined by the domain name.
- **Breadcrumb**: The trail showing the page's position within the site's hierarchy.

## Text result visual elements

A text result includes:

- **Attribution**: Source information for the web page.
- **Title link**: The title that links to the web page. Learn how to influence title links.
- **Snippet**: The description or summary part of the search result. Learn how to control snippets.
- **Byline date**: The date Google estimates the page was updated or published.
- **Sitelinks group**: Two or more links from the same domain clustered together under a text result.
- **Text result image**: The most relevant image from the page for the given query.
- **Rich attributes**: Additional information about the page (e.g., review stars, recipe information), typically powered by structured data.

## Image result visual elements

- **Image thumbnail**: Thumbnail for the indexed image.
- **Attribution**: Source information for the web page embedding the image.

## Video result visual elements

- **Video thumbnail**: Thumbnail for the indexed video.
- **Title link**: Title link for the video landing page.
- **Attribution**: Source information for the video landing page.
- **Upload date**: The date the video was published.

## Exploration features

### Related searches group
A cluster of related searches that other people have done. Tapping takes the user to another search results page.

### Related questions group
A cluster of questions related to the initial search (also known as "People Also Ask"). When expanded, shows a featured snippet.
