# google-search-seo

Офлайн-архив официальной документации Google по SEO (поисковой оптимизации для Google Search), скопированной с `developers.google.com/search/docs`.

Проект содержит ~158 markdown-файлов, организованных в 7 разделов:

| Раздел | Содержание |
|---|---|
| **01-introduction** | Введение в SEO, ссылки на базовые ресурсы |
| **02-search-essentials** | Основы Google Search: технические требования, политики спама |
| **03-seo-fundamentals** | Руководство для начинающих по SEO, как работает поиск, создание полезного контента, SEO и генеративный ИИ |
| **04-crawling-and-indexing** | Кроулинг и индексация: файлы sitemap, robots.txt, canonical-URL, мобильная индексация |
| **05-ranking-and-search-appearance** | Ранжирование и внешний вид в поиске: сниппеты, структурированные данные, Core Web Vitals, изображения, видео, локальные функции |
| **06-monitoring-and-debugging** | Мониторинг через Search Console, отладка падения трафика, Google Trends, защита от злоупотреблений |
| **07-site-specific-guides** | Руководства для конкретных типов сайтов: e-commerce, контент для взрослых |

Каждый файл содержит исходный URL на документацию Google и дату последнего обновления (2025–2026). Это справочный материал, а не исполняемый код.
